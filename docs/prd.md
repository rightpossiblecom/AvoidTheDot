# 🎮 AvoidTheDot

**Genre:** Reflex Survival Arcade  
**Core Feeling:** Tension → Panic → Flow State  
**Main Benefit:** Enhances reflexes & movement precision

---

# 🔴 Game Vision

**AvoidTheDot** is a minimalist survival game where:

A dangerous bouncing dot moves unpredictably across the screen →  
Player keeps their finger moving to avoid contact →  
The longer they survive, the harder it gets.

Simple concept.  
Pure tension.

The game should feel:

- Fast
- Stressful in a fun way
- Clean
- Reactive
- Addictive

This is the kind of game where:

> “I survived 42 seconds… one more try.”

---

# 🎯 Core Gameplay Experience

## 🔁 Main Loop

1. Player places finger on screen
2. Enemy dot starts bouncing
3. Player moves finger to avoid it
4. Dot speed increases over time
5. Survive as long as possible

Touch the enemy dot:  
❌ Game Over

---

# 🧠 The Core Tension

The magic of the game is:

- The player is ALWAYS in danger
- There’s no safe place forever
- Movement becomes instinctive
- Panic slowly builds

It should create:  
😰 “WHERE IS IT GOING?!”

But still feel fair.

---

# 🎮 Control Feel (MOST IMPORTANT)

Player movement must feel:

- Instant
- Smooth
- Precise
- Natural

The finger becomes the “player.”

No lag.  
No delayed movement.

This game lives or dies on responsiveness.

# 🌌 Aesthetic Direction

## Theme:

### ⚫ Minimal Neon Survival

The game should feel:

- Modern
- Minimal
- High-focus
- Intense

Not cluttered.  
Not childish.

---

# 🎨 Visual Identity

## Background

- Deep dark matte background
- Slight gradient
- Clean empty space

The emptiness increases tension.

---

## Enemy Dot

The bouncing dot should feel alive.

### Visual Traits:

- Bright glowing core
- Subtle motion trail
- Dynamic glow pulse
- Slight speed streaks at high velocity

Player should FEAR the dot.

---

## Player Indicator

Instead of showing just a finger point:

Use:

### ✨ Small energy orb / light ring

Feels cleaner and more immersive.

---

# ⚡ Gameplay Feel

## Early Game

😌 Slow and manageable

Player learns movement.

---

## Mid Game

😬 Dot speed increases

Player begins reacting instinctively.

---

## Late Game

😰 Chaos

Dot bounces rapidly.  
Heart rate rises.  
Tiny mistakes matter.

This tension curve is the game.

---

# 🔥 Difficulty Progression

Game becomes harder by:

- Increasing dot speed
- Increasing bounce unpredictability
- Adding wall ricochet effects
- Introducing multiple dots later

But progression must feel smooth.

Never unfair.

---

# 💥 Collision Feedback

## On Game Over

When player touches the dot:

- Sharp impact flash
- Tiny freeze-frame moment
- Screen pulse
- Strong vibration
- Dot explosion effect

Game over should feel dramatic.
