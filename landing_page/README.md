# AvoidTheDot — marketing site

Next.js landing page for **AvoidTheDot**: a minimal reflex survival game (see `docs/prd.md`).

## Commands

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Production build:

```bash
pnpm build
pnpm start
```

## Assets

- App icon: `public/app_logo.png` (copy stays in sync with Flutter `assets/app_logo.png` at repo root).

## Stack

Next.js 16, React 19, Tailwind CSS v4, Framer Motion.
